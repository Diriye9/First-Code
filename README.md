# First-Code
This repository contains a local, static mirror of `sahaltech.com` for a company profile demo.

Open the page:

```bash
xdg-open company-profile/sahaltech.com/index.html || open company-profile/sahaltech.com/index.html
```

Notes:
- All CSS/JS/assets are mirrored locally so it works offline.
- Visual design and layout are kept identical to the source.
